## 📌 Project Overview

The Automated Network Request Management System is a ServiceNow-based
application designed to automate and streamline network-related service
requests.

## 🎯 Objective

To automate the complete lifecycle of network requests, reduce manual
effort, improve request processing, and provide centralized tracking.

## ⚙️ Technologies Used

- ServiceNow
- Flow Designer
- Service Catalog
- Business Rules
- Client Scripts
- UI Policies
- ACLs
- Notifications
- Approvals
- Reports & Dashboards

## 🔄 Request Types

- VPN Access
- IP Allocation
- Firewall Changes
- Network Troubleshooting

## 🔧 Key Features

- Automated request creation
- Assignment group routing
- Approval workflow
- Automated notifications
- Request tracking
- Workflow automation

## 🔁 Workflow

User submits request
        ↓
Request created
        ↓
Request type identified
        ↓
Assignment group assigned
        ↓
Manager approval
        ↓
Request fulfillment
        ↓
Email notification
        ↓
Request completed

## 📊 Project Components

### Service Catalog
Network-related request variables and catalog item.

### Flow Designer
Automates request assignment, approvals, notifications and fulfillment.

### Security
ACLs and role-based access control.
